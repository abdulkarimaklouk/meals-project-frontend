# Restaurant Management System - Frontend

## Overview

A responsive frontend for a restaurant management system built with HTML, CSS, and JavaScript. The application connects to the backend REST API to manage meals, inventory, ingredients, and customer orders through an intuitive user interface.

## Features

- Dashboard
- Meal Management
- Inventory Management
- Order Management
- Responsive UI
- REST API Integration

## Tech Stack

- HTML
- CSS
- JavaScript
